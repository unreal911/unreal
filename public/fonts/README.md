# Portfolio fonts

DM Sans and Manrope are served locally to avoid an extra render-blocking stylesheet request. These Latin WOFF2 subsets are the same resources previously served by Google Fonts, including Spanish accented characters. Their SIL Open Font Licenses are included alongside the files.

Sources:

- DM Sans: https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K6z9mXg.woff2
- Manrope: https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSvfedN4.woff2
- Licenses: https://github.com/google/fonts/tree/main/ofl/dmsans and https://github.com/google/fonts/tree/main/ofl/manrope
